# Card artwork credits

The 48 traditional Hwatu card illustrations in `public/cards/*.png` are from the Wikimedia Commons **PNG Hwatu** set. The artwork is by Marcus Richert, based on Hanafuda graphics by Louie Mantia, Jr. The Commons PNGs are resized thumbnails of the card artwork; this project maps them to its internal card IDs and serves the PNG files directly for reliable browser rendering.

- Source set: [Wikimedia Commons — PNG Hwatu](https://commons.wikimedia.org/wiki/Category:PNG_Hwatu)
- Individual file history and attribution: linked from the source set above

- Changes: resized to the 500 px Commons thumbnail; filenames mapped to this game's card IDs. The card artwork itself is unaltered.
